# 계획 사전 조사 기록 (2026-09-14)

구현 계획을 추측이 아니라 확인한 사실 위에 세우려고 한 조사의 기록이다.
조사 AI가 결과를 내고, **다른 AI가 반박하며 다시 검증**했다.

> 이 폴더의 코드(`prototypes/`)는 **검증에 쓴 시험용 코드의 사본**이다. 앱에서 직접 import 하지 않는다.
> 구현은 계획서(`docs/superpowers/plans/`)에 따라 `prep/`, `assistant/`로 옮기면서 시험을 붙인다.

## 3. 뒤쪽 계획서로 넘기는 주의점 (읽은 것만)

- **인용 기능**: 도구 결과 안에 `search_result` 블록을 넣고 인용을 켤 수 있다(beta 헤더 불필요). 인용되는 가장 작은 단위는 **블록 하나 통째**다. 그래서 쪽 글자를 문단 단위 블록으로 쪼개서 넣어야 한다. PyMuPDF 글자에는 빈 줄이 없으므로, 계획 1에서 문단마다 한 줄로 만들어 둔다.
- 예시 코드의 답 조립은 마지막 턴만 읽어서 앞 턴의 인용을 잃는다. 한도에 닿았을 때 `tool_choice`를 바꾸면 캐시가 깨진다. 계획 2에서 고친다.
- **가장 긴 장**은 2023년치 제3장이다(110쪽, 공백 뺀 글자 약 8만 자). 요약의 토큰 상한(15만)을 넘을 수 있으니, 계획 3에서 토큰을 재고 필요하면 절 단위로 나눈다.
- 판 이름과 다룬 해가 헷갈린다. 「2021 외교백서」는 2020년치다. 2023년치 인사말은 자기 책을 "2024년 외교백서"라 부른다.
- 부록(일지 · 현황표)이 찾기 상위 결과를 많이 차지한다. 결과에 부록 여부를 표시한다.
