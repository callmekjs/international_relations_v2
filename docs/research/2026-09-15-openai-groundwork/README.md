# 계획 2 사전 조사 기록 — OpenAI gpt-5.6-sol (2026-09-15)

2026-09-15 주석님이 LLM을 Claude에서 **OpenAI gpt-5.6-sol**로 바꾸기로 했다. 계획 2(조수 + 질문답변)를 쓰기 전에 조사 4개를 돌리고, 조사마다 반박 검증을 붙였다.
실제 API 호출 요금은 모두 합쳐 **$0.077**이었다.

> 이 폴더의 코드는 조사 · 검증에 쓴 시험용 코드다. 앱에서 import 하지 않는다. 구현은 계획 2에서 시험과 함께 새로 만든다.
> 백서 원문이 길게 들어간 파일(표본 쪽 글자, 전체 시험 출력)과 OpenAI 문서 사본은 저작권 때문에 올리지 않았다.

## 2. 계획 2에 반영하는 결정

| # | 결정 | 근거 |
|---|---|---|
| O1 | **Responses API**를 쓴다. Chat Completions는 쓰지 않는다 | GPT-5.6에서 Chat Completions의 함수 도구는 추론을 끈 상태에서만 됨. OpenAI는 새 프로젝트에 Responses를 권장 |
| O2 | 스트리밍으로 받고 `store=False`, 매 턴의 출력 항목(암호화된 추론 포함)을 직접 되돌려 보낸다 | 저장하면 30일 이상 보관되고 대시보드에 남음. 도구 호출이 있는 추론 항목은 반드시 되돌려 보내야 함 |
| O3 | 최종 답은 스트림의 `response.completed` · `response.incomplete` · `response.failed` 이벤트에서 꺼낸다. SDK의 `get_final_response()`와 `output_text`에 기대지 않는다 | 앞의 것은 중단 시 예외를 내고, 뒤의 것은 사전 설명(commentary)까지 섞어 버림 |
| O4 | 도구 10번 · 누적 입력 상한은 **우리 루프가** 센다(병렬 호출 포함). 마지막 호출은 도구를 막고 답을 받는다 | `max_tool_calls`는 내장 도구에만 적용 |
| O5 | **근거 = 쪽 id + 문단 번호 + 짧은 구절**(주석님 결정). 구절이 그 문단에 그대로 있으면 "확인됨", 문단은 맞는데 구절이 다르면 "문단만 확인", 그 밖은 "근거 없음" | "조금 다름"을 통과시키면 증가→감소 같은 뜻 뒤집기가 449건 중 447건 통과했음 |
| O6 | 답은 strict JSON 스키마(문장 · 근거 · 상태)로 받는다. 상태(answered / not_found / not_in_corpus / refused)는 답에 넣고 따로 도구로 받지 않는다 | 엄격 스키마와 도구를 한 요청에 함께 쓰는 것은 luna로 확인. sol에서 도구 호출 뒤 JSON 답까지 이어지는지는 첫 실제 호출에서 확인 |
| O7 | 비교 대조 규칙: 숫자 사이의 점 · 하이픈은 지우지 말고 하나의 구분자로 바꾼다. 구절 앞뒤의 "…"와 마침표는 떼고 비교한다. 구절은 12자 이상이어야 한다 | 1·2차→12차, 47명 속 7명 같은 거짓 "확인됨"을 검증에서 발견 |
| O8 | 틀린 쪽을 인용했을 때 다른 쪽으로 옮겨 붙이는 보정은 **같은 해 안에서만** 하고, 화면에 "쪽 바로잡음"으로 따로 표시한다 | 다른 해로 조용히 옮겨져 연도 비교가 망가지는 경우를 검증에서 발견 |
| O9 | 도구 결과는 `json.dumps(..., ensure_ascii=False)`로 보낸다 | 기본값(ASCII 이스케이프)은 토큰이 2.9배 |
| O10 | 요금 계산 = (입력 − 캐시 읽기 − 캐시 쓰기) × $4 + 캐시 읽기 × $0.40 + 캐시 쓰기 × $5 + 출력 × $20 (100만 토큰당). `service_tier`도 기록한다 | GPT-5.6은 캐시 쓰기에 1.25배를 매김. Flex는 절반 가격 |
| O11 | 요금 안전장치: OpenAI **프로젝트를 공개용 · 개발용으로 나누고** "Enforce a hard limit"을 켠다(공개용 약 $12, 늦게 적용되는 걸 고려). 선불 자동 충전은 끈다. 앱의 방문자 · 하루 한도는 그대로 둔다 | 강제 한도는 직접 켜야 하고 늦게 막힘. 이 계정은 사용 등급이 높아(최소 Tier 3) OpenAI 기본 한도가 월 $1,000 이상 |
| O12 | 클라이언트는 `max_retries=0` + 앱에서 최대 2번 재시도. 스트림 글자가 이미 나간 뒤, 그리고 결제 · 한도 오류(`project_spend_limit_exceeded` 등)는 재시도하지 않는다. timeout을 명시한다 | SDK 기본값은 한도 초과 429까지 재시도하고, timeout 600초 × 3번까지 걸림 |
| O13 | 모든 요청에 `safety_identifier` = 방문자 해시(64자)를 보낸다. 방문자 질문만 무료 moderation으로 거른다 | 사용자 구분 없이 안전 차단이 걸리면 조직 전체가 막힐 수 있음. 도구 결과(전쟁 · 핵 주제)는 거르지 않음 |
| O14 | `openai` SDK는 3.14.0으로 고정하고, Gradio와 함께 설치되는지 계획 3 전에 확인한다 | 3.14.0은 httpx2를 쓰고 Gradio는 httpx를 씀 |

## 3. 아직 모르는 것 (첫 실제 호출 · 계획 3에서 확인)

- sol의 **추론 토큰 양**: 질문 1번 요금이 약 100~480원으로 크게 달라짐. 첫 호출에서 요청별 사용량을 기록해 다시 계산한다.
- sol이 도구 호출 뒤 **엄격 JSON 답**을 문제없이 내는지, 사전 설명(commentary)을 끼워 넣는지.
- 강제 한도가 **얼마나 늦게, 얼마나 넘겨서** 막히는지. 월 기준 시간대.
- 토큰 세기 기능(input_tokens)이 과금되는지(문서에 없음).
- sol 할인가는 "최소 2026-11-21까지". 그 뒤 가격은 아직 없음.
- 익명 공개 앱과 OpenAI 약관(지원 국가, 미성년자 동의)의 관계는 위험으로 기록만 해 둔다.
